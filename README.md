# iPad 程式碼極速預覽神器 (ipad-preview)

> 專為國中學生 iPad 課堂打造的 HTML / JS 程式與遊戲免痛預覽工具。

## 1. 目標
解決學生在 Google Canvas 或 AI 工具產出程式碼後，因 iPad 複製困難、操作不便、或平台沙盒限制而無法在 iPad 上預覽遊戲的問題。
提供「一鍵讀取剪貼簿貼上」、「檔案點選上傳」、「全螢幕試玩」、「音效支援」與「單檔 HTML 下載」功能。

## 2. 目前進度
- 狀態：已建立單檔極速預覽網頁原型 `index.html`，並發布至 GitHub Pages
- 線上網址：https://andytsai600-rgb.github.io/ipad-preview/
- GitHub 儲存庫：https://github.com/andytsai600-rgb/ipad-preview

## 3. 檔案清單
- `index.html`：單檔預覽器主程式（專為 iPad 觸控優化）
- `README.md`：專案說明（本檔）
- 成果交付副本：`C:\AI\outputs\ipad-preview.html`

## 4. 不能公開的東西
- 任何私有憑證、學生個人資料

## 5. 如何執行
- 學生直接使用 iPad Safari 開啟 `https://andytsai600-rgb.github.io/ipad-preview/`
- 本機可直接以瀏覽器開啟 `index.html`
